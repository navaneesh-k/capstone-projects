# Project 5: Secure Linux Server Permissions

**Objective:** Implement user-based access restrictions on an Ubuntu Linux server.

**Implementation:**
- Created three Linux users: dev1, dev2, and guest1.
- Created a developers group and added dev1 and dev2.
- Configured a secure directory using Linux ownership and permissions.
- Assigned group-based read and write permissions.
- Restricted access for unauthorized users.

**Testing:**
- Verified that dev1 could read the protected file.
- Verified that dev2 could modify the protected file.
- Confirmed that guest1 received Permission denied errors.

**Result:**
Successfully implemented Linux file permissions and group-based access control, ensuring only authorized developers could access protected project files.
